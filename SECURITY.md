# Security policy

Sigma 2.0 is an alpha research implementation. No release is currently
supported for production-security use and no construction has completed an
independent cryptographic audit.

Please report suspected security issues privately to the maintainer rather than
opening a public issue. Include the affected suite/version, a minimal reproducer
and the expected impact. Do not include real secrets or third-party data.

Interoperability stability of a suite or vector does not imply a security
guarantee. The project will publish advisories, new suite identifiers and
migration guidance when a wire-compatible correction is impossible.
