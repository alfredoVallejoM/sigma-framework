## Historial de revisión

### Primera revisión — FAIL

- Commit: `ca5e141e5d4d4ec5dfbd059738e99e30d1a49e7e`.
- El perfil explícito no estaba ligado a un `SuiteIdV3` coherente.
- Los discriminadores se validaban después de copiar el cuerpo completo.
- Faltaba un KAT explícito e independiente.
- Faltaba una matriz negativa explícita para deformaciones del wire.

Correcciones versionadas en
`8e489e619e39ea95b66dc4d12a39b44d700a5149`: rechazo temprano de
discriminadores, KAT SHA-256 fijo y matriz negativa para campo desconocido,
duplicado, orden, trailing bytes, longitud, suite, profile y domain.

### Segunda revisión — FAIL

- Commit: `8e489e619e39ea95b66dc4d12a39b44d700a5149`.
- `EXPLICIT_AUDIT_V3` estaba registrado como suite ejecutable aunque sólo debía
  identificar el envelope exterior.
- Eso permitía crear un contexto o trayectoria `0x0302` que no podía publicarse
  coherentemente y anchors o bindings con algoritmos incompatibles.

Correcciones versionadas en
`0166cf577803e2bee8f08a1c946dc46d143e36a0`: separación entre el catálogo
inmutable de suites ejecutables y el catálogo inmutable de envelopes; rechazo
del ID exterior en contextos, anchors y bindings; descriptor congelado del
envelope con suite, output profile, domain y output profile interior.

### Tercera revisión — PASS

- Commit: `0166cf577803e2bee8f08a1c946dc46d143e36a0`.
- Todos los hallazgos previos quedaron resueltos.
- No se detectaron hallazgos nuevos.

## Evidencia adversaria final

### Envelope exterior cerrado

- `get_suite_v3(EXPLICIT_AUDIT_V3)` rechaza.
- `SigmaContextV3.for_suite(EXPLICIT_AUDIT_V3, ...)` rechaza.
- `AnchorV3.from_bytes()` rechaza una suite mutada a `EXPLICIT_AUDIT_V3`.
- `PersistentBinding.from_bytes()` rechaza un anchor con esa mutación.
- `get_evidence_envelope_v3(REFERENCE_IAP_V3)` rechaza.
- El descriptor exterior declara coherentemente `EXPLICIT_AUDIT_V3`,
  `EXPLICIT_BINDING`, `EXPLICIT_EVIDENCE` e interior `IMPLICIT_J`.

### Inmutabilidad y rechazo temprano

- Las asignaciones sobre `_SUITES_V3` y `_EVIDENCE_ENVELOPES_V3` fallan con
  `TypeError`.
- `EvidenceEnvelopeDescriptorV3` rechaza mutaciones por ser un dataclass
  congelado.
- La instrumentación de slices confirmó que suite, profile y domain corruptos
  se rechazan sin copiar el cuerpo completo: el slice máximo observado fue de
  10 bytes.
