## 2. Inclusion proof structure

`InclusionProofV1` binds:

- TreeProfile V1;
- complete TreeRoot V1;
- leaf index;
- exact leaf byte length;
- canonical leaf-to-root sibling path.

Each step binds:

- LEFT/RIGHT orientation;
- sibling start/count/byte_length/height;
- the complete four-component digest vector.

The target offset is derived rather than serialized:

    offset = leaf_index * 65,536

This avoids a second authority for leaf geometry.

## 3. Range proof structure

`RangeProofV1` binds:

- TreeProfile V1;
- complete TreeRoot V1;
- exact start and length;
- exact first-leaf prefix complement;
- exact last-leaf suffix complement;
- canonical maximal witness subtrees covering all leaves outside the touched leaf span.

The verifier receives only:

    range_bytes + proof

and reconstructs the root without a source/path/file handle.

## 4. Canonical cover

For the target leaf span L, the witness cover is defined recursively:

1. if a canonical subtree is disjoint from L, emit it and do not descend;
2. if it is a singleton intersecting L, emit nothing;
3. otherwise split by the ST0 largest-power canonical split and recurse.

This gives the unique maximal canonical complement cover.

- verifies complete roots.

## 9. O12 cheap rejection evidence

A defect was found during post-implementation review:

The first one-shot helper initially did:

    TreeProofIndex(data).prove_range(start, length)

which meant an invalid range could trigger complete Tree hashing before range
validation.

Remediation:

`prove_range(data,start,length)` now validates:

- types;
- positive length;
- u64 bounds;
- end overflow;
- source bounds;

before constructing `TreeProofIndex`.

A bomb-index test confirms invalid one-shot ranges reject without index creation.

The parser and verifier likewise validate interval/edge/witness geometry before
any leaf hashing.

Disposition:

    FIXED — O12 PASS

## 10. Gate orchestration finding

The first closure run timed out because the campaign reserialized every one of
the 200,000 generated proofs solely to compute audit hashes.

This was accidental campaign overhead, not proof semantics.

Remediation:

- 100k/100k generation thresholds were preserved;
- every proof still constructs/validates its canonical object;
- deterministic geometry is streamed for every case;
- full wires are sampled deterministically for the campaign hash;
- differential and mutation corpora continue to serialize full wires.

After remediation, the full closure-scale campaign passed in approximately
10 seconds on the local execution host.

No scientific or structural threshold was lowered.

## 11. Disclosure boundary

A partial range proof must reconstruct complete edge leaves because ST0 hashes
65,536-byte leaves.

Therefore V1 includes exact prefix/suffix complements.

Consequence:

A range proof may reveal up to:

    2 * (65,536 - 1) bytes

outside the requested interval.

ST2 explicitly makes no privacy, zero-knowledge or private selective-disclosure
claim.

Avoiding this leakage requires an additional subchunk commitment geometry and is
not silently added to V1.
