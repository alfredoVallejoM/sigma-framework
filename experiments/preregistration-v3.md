2. R13 design pilots, which are disposable;
3. R14 discovery/pilot budgeting, which cannot enter the paper as evidence;
4. R15 holdout/confirmatory results;

No R13 or R14 pilot observation may be copied into a result table, effect-size
estimate or confirmatory figure.

## 3. Confirmatory claims

Primary empirical claims:

- C04: equality of visible state alone does not imply trajectory coalescence;
- C05: complete dynamic state `(H_i,S_i)` is the relevant coalescence target;
- C06: multi-state/window security must be studied under explicit separation,
  freshness and reduced-attack models;
- C10: Deep inherits a scalar-fold bottleneck;
- C11: DeepVector preserves complete-vector dependence;
- C14: unbiased parameter sampling does not eliminate adversarial grinding;
- C16: KDF composition may permit early rejection before full Sigma work;
- C17: PoW nonce selection may bias trajectory cost.

Secondary empirical claims:

- C08/C09: layout is history-adaptive but layout collisions do not erase the
  serialized history distinction;
- C12: multiple branches receive no additive-security credit; correlation and
  broken-control evidence is descriptive;
- C13: the concrete `(t,k)` derivation is tested for joint distribution and
  observable correlations.

Boundaries not promoted to positive claims:

- C15: Sigma does not create password entropy or memory-hardness;
- C19: Python execution has no constant-time claim;
- C20: no ASIC/GPU/VDF/PoSW claim exists.

Canonicality, causal semantics, backend equivalence and signature semantics are
covered by theorem/conformance evidence and are not re-estimated as hardness
claims in R15.

## 7. Discovery and holdout

Heuristic tuning is allowed only before R14 freeze. If additional discovery is
required for a future attacker, it receives a new campaign/freeze.

The frozen R15 configs are holdout/confirmatory only. Exhaustive reduced
experiments do not receive an artificial discovery split.

## 8. Terminal states and stopping rules

Canonical terminal states are:

- success;
- no-success;
- censored;
- timeout;
- error.

A first-hit experiment may stop on its predeclared success event. A run with no
success is only `no-success` after exhausting its declared budget. Timeout is
not no-success. Error is not censored or silently dropped. Resource-safety
termination is censored with an explicit reason.

No run stops because of a p-value, interim effect direction or desired figure.

## 9. Primary analyses

- rare events/proportions: exact binomial or predeclared exact alternatives;
- first-hit/right-censored work: Kaplan-Meier median/RMST;
- scaling: `log2(work)` versus width with deterministic bootstrap slope CI;
- parameter uniformity: joint GOF, with Monte-Carlo exact fallback when
  asymptotic chi-square conditions fail;
- correlations: permutation-controlled MI/correlation;
- paired KDF/PoW/mitigation costs: paired ratio/difference with bootstrap CI;
- TMTO: Pareto frontier in offline work, online work and memory;
- performance/cost: median and quantiles with host-stratified bootstrap;
- external statistical batteries: descriptive calibrated anomaly families only.

Holm controls the family-wise error of primary hypotheses within a declared
family. BH/FDR may be used only for explicitly exploratory secondary outputs.

No statistical battery is interpreted as a cryptographic proof.

## 10. Sample sizes and budgets

Sample size is frozen in each config. The main design uses:

- 128 or 256 replicates for central reduced collision/history families;
- 64 replicates for TMTO, KDF, PoW, mitigation and branch controls;
- 32 replicates for the 93-cell joint `(t,k)` distribution with 93,000
  samples per replicate;
- 32 external streams per construction/corpus for STAT-01.

Candidate/query horizons scale with reduced width and are right-censored at the
exact config budget. No R15 run increases its horizon or replicate count in
response to an uninteresting result.

## 11. KDF

PARAM-04 is paired across identical password/salt/Argon2id inputs:

1. Argon2id alone;
2. Argon2id + fixed-cost Sigma;
3. Argon2id + input-derived-cost Sigma.

Primary endpoint: work per wrong guess. Secondary endpoint: early-reject rate.
Argon2id retains all memory-hardness attribution.

## 12. PoW

PARAM-05 compares fixed trajectory cost with derived trajectory cost on matched
challenge/payload sets. Primary endpoint: throughput ratio after including
nonce-selection work. Nonce selection cost cannot be omitted.

PARAM-06 compares only the three frozen variants:

- input-derived;
- context-fixed;
- cost-bucketed.

No new mitigation is added during R15.

## 13. History and multi-state windows

For window claims, equality events are interpreted only together with the R13
separation/freshness decomposition. An empirical fit near `2^{-kn}` is not
reported as concrete `kn` security bits.

HIST-01 distinguishes visible crossings from full-state joins.
HIST-02 targets `(H_i,S_i)`.
HIST-05 varies history width.
RED-02 varies output width and window length.

## 14. Deep / DeepVector

BRANCH-05 freezes normal and branch/fold failures for Deep, including constant
and truncated fold controls. BRANCH-06 freezes vector branch perturbations.

Physical vector width and conservative security width remain separate columns.

## 15. External statistical controls

STAT-01 freezes:

- SHA-512;
- SHA3-512;
- BLAKE2b-512;
- SHAKE256-512;
- R12.5 WideOnce/Deep/DeepVector;
- deliberately broken control;

over counter, ff-tail and alternating corpora.

Declared batteries are NIST STS, PractRand, TestU01 SmallCrush and Crush.
Unavailable tests are recorded as not-applicable; they are not silently
removed. BigCrush is not part of this freeze.

## 16. Hosts and execution

At minimum:

- Linux x86-64;
- macOS ARM64;
- Windows x86-64 for portability/conformance-relevant cells;
- two independently administered physical hosts for performance/KDF/PoW
  measurements used in the paper.

Every run records interpreter, dependencies, CPU/OS, worker policy, artifact
hash, commit, config hash and preregistration hash. Host-specific measurements
are stratified rather than blindly pooled.

## 17. Synthetic analysis freeze

Before R15, all declared figure/table transformations must execute against
synthetic schema-valid records. Synthetic records are marked as such and are
never admissible as evidence.

The frozen figure registry is `experiments.r14_analysis.FIGURES_V3`.

## 18. Integrity and invalidation

R14 binds:

- this preregistration;
- every confirmatory config;
- R14 protocol/schema;
- R13 registry/schema;
- R12.5 corpus/reference;
- analysis/figure schemas;
- source commit;
- wheel/sdist/SBOM/checksums.

A semantic construction change reopens R12.5. An attacker/protocol/config or
analysis change after R14 PASS creates a new freeze/campaign. A runtime artifact
whose SHA-256 is not the archived R14 artifact is not a valid R15 executor.

## 19. Publication rule

R15 publishes positive, negative, censored, timeout and error outcomes. A
negative attack result means only that no success occurred within the frozen
budget. It is never rewritten as proof that no better attack exists.

R16 external reproduction and cryptographic review remain necessary before any
stable security claim.
